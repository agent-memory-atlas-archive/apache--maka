# maka-web

[English](README.md)

通过作用域网络能力实现 Web 抓取与搜索。`fetch` 和 `search` 管理内容策略，`settings` 管理提供商配置，`provide` 注册 Host 工厂。该服务可以在不包含 Agent 引擎的 Host 组合中运行。

[源码](src/lib.rs) · [Cargo 配置](Cargo.toml)
