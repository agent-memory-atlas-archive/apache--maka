# maka-acp-native

[English](README.md)

注册原生 ACP Executor 服务，将执行引擎连接到导入的进程、文件和表单服务。`provide` 将工厂加入 Host 注册表。可执行实例和绑定由产品组合选择；链接该服务本身不会授予进程访问权。
